# Quiet Manga

漫画柜的沉浸式阅读脚本。保留原网站的漫画来源，提供稳定的整页和连续阅读界面。

## 使用

已安装的 Chrome：刷新漫画章节页，点击右下角 **沉浸阅读**。

其他浏览器安装：在 Tampermonkey 中新建脚本，用 `quiet-manga.user.js` 的全部内容替换编辑器内容并保存。脚本只匹配漫画柜章节地址。

- **整页**：完整显示漫画，← / → 翻页；双击或点击“放大”查看细节，拖动移动，Esc 恢复。
- **连续**：上下滑动阅读；双指横滑或捏合调宽，设置中也可调整宽度。图片只加载当前页附近；远处保留尺寸占位。
- **页码**：输入后按 Enter 跳转。空格向下读一屏，Shift + 空格向上。
- **全屏**：右上角独立的四角展开图标。画布铺满屏幕；底部没有工具栏。
- **控件**：翻页、页码、缩放位于右侧。向下滚动隐藏，向上滚动或把鼠标移到顶部/右侧边缘时显示。
- **设置**：自动进入、目录、上一章和下一章。点击面板外任意位置收起。
- **退出**：还原原网页及原滚动位置。再次进入会恢复阅读进度。

整页与连续模式切换、改变宽度和窗口尺寸时，保持当前页及连续阅读的位置。明确带有 `#p=N` 的链接优先于保存的进度。

## 范围

已在 macOS 上的实际 Chrome + Tampermonkey 5.5.1 环境测试，包含现有扩展环境。`www.manhuagui.com` 的目标章节及相邻章节做实站验证；`tw` 域名使用同一适配规则，未单独实测。移动端浏览器不在本次验收范围内。

脚本需要原站当前图片可以正常加载。它读取该页已提供的清单和图片地址，不提供搜索书库、离线下载或跨设备同步。进度保存在当前浏览器的网站本地存储中。它遮住原站界面，但不会充当网络广告拦截器。网站清单结构变化时，适配器会明确报错。

## 开发与验收

```sh
npm ci
npm run build
npm test
npm run serve
```

在 Chrome 打开 `http://127.0.0.1:8766/tests/fixture.html`，点击“运行验收测试”；结束后再打开 `http://127.0.0.1:8766/tests/responsive.html` 运行尺寸测试。两组浏览器测试应顺序运行。

- `core.js`：清单解析、地址验证、几何计算。
- `reader.js`：阅读界面、输入、图片调度与进度。
- `build.cjs`：将 lz-string 和源码打包为单个 userscript，运行时无远程代码依赖。
- `tests/`：故障注入服务、交互与响应式回归。
- `ACCEPTANCE.md`：实现前制定的验收清单。
- `TESTING.md`：实测结果、修复循环与测试边界。
