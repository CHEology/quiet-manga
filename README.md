# Quiet Manga

漫画柜的沉浸式阅读脚本。保留原网站的漫画来源，提供稳定的整页和连续阅读界面。

## 使用

已安装的 Chrome：刷新漫画章节页，点击右下角 **沉浸阅读**。

iPad Safari 的 Tampermonkey 扩展和桌面使用同一个 `quiet-manga.user.js`。触屏首次进入使用连续模式，轻点漫画切换顶栏。

桌面 Tampermonkey 安装：在 Tampermonkey 中新建脚本，用 `quiet-manga.user.js` 的全部内容替换编辑器内容并保存。脚本只匹配漫画柜章节地址。

- **整页**：完整显示漫画，← / → 翻页；双击漫画、捏合或按 Z 查看细节，拖动移动，Esc 恢复。原尺寸下可单指横划翻页。顶栏隐藏后翻页保持隐藏，鼠标移到顶部、触屏轻点或按 Tab 可唤出。
- **双页**：整页和连续模式均可从「设置 → 排版」选择。横屏且画布宽度达到 800px 时，两张相邻竖图等高并排；选择「首页单独显示」可把 1–2、3–4 改为 1、2–3、4–5。宽图、方图和余下的一页单独显示。单双页、阅读方向和首页选项按作品保存。
- **翻组**：页码显示当前范围，点击数字可跳到其中任一原始页码。从右向左时，左箭头前进，右箭头回退；从左向右时相反。空格沿阅读顺序前进，双击或捏合缩放整组。
- **连续**：向下滚动，单页每行一页，双页每行一组；双指横滑或捏合调宽，设置中也可调整宽度。图片只加载当前页附近；远处保留尺寸占位。
- **顶栏**：左侧为目录、上一章、下一章；中间为对称排列的页码和翻页符号；右侧为阅读模式及全屏、设置、退出图标。
- **页码**：输入后按 Enter 跳转。空格向下读一屏，Shift + 空格向上。
- **全屏**：右上角独立的四角展开图标。画布铺满屏幕；底部没有工具栏。
- **控件**：没有侧栏或底栏。向下滚动隐藏顶栏，向上滚动或把鼠标移到顶部边缘时显示。
- **目录**：长列表占满弹框可用高度，少量搜索结果按内容收缩。在当前页面的浮层内查看和搜索章节，当前章节用细蓝框标记。
- **切章**：原地更新图片和网址，保留沉浸、全屏、阅读模式和宽度。连续模式的章末留有空间及上下章入口。浏览器返回可恢复旧章节进度。
- **设置**：外观（深色、浅色或跟随系统）、宽度和自动进入。点击面板外任意位置收起。
- **退出**：还原原网页及原滚动位置。再次进入会恢复阅读进度。

整页与连续模式切换、改变宽度和窗口尺寸时，保持当前页及连续阅读的位置。明确带有 `#p=N` 的链接优先于保存的进度。

## 范围

已在 macOS 上的实际 Chrome + Tampermonkey 5.5.1 环境测试，包含现有扩展环境。`www.manhuagui.com` 的目标章节及相邻章节做实站验证；`tw` 域名使用同一适配规则，未单独实测。iPad 适配在 macOS Safari 与 Chrome 上用合成触摸与变尺寸视口验证；未连接实体 iPad，未验证原生手势或 iPad 上实际安装。适配范围为 www / tw 章节页，不包含 m 移动站。

脚本需要原站当前图片可以正常加载。它读取该页已提供的清单和图片地址，不提供搜索书库、离线下载或跨设备同步。进度保存在当前浏览器的网站本地存储中。它遮住原站界面，但不会充当网络广告拦截器。网站清单结构变化时，适配器会明确报错。

## 开发与验收

```sh
npm ci
npm run build
npm test
npm run serve
```

在 Chrome 打开 `http://127.0.0.1:8766/tests/fixture.html`，点击“运行验收测试”；结束后打开 `http://127.0.0.1:8766/comic/900/1.html` 运行章节测试，再打开 `http://127.0.0.1:8766/tests/responsive.html` 运行尺寸测试。三组浏览器测试应顺序运行。触屏测试另开 `http://127.0.0.1:8766/tests/ipad.html?run`，使用同一成品脚本和本地几何图，覆盖 7 组视口。

- `core.js`：清单解析、地址验证、几何计算。
- `touch.js`：单指轻点、双指捏合、取消与逐帧合并。
- `reader.js`：阅读界面、输入、图片调度与进度。
- `build.cjs`：将 lz-string 和源码打包为单个 userscript，运行时无远程代码依赖。
- `tests/`：故障注入服务、交互与响应式回归。
- `ACCEPTANCE.md`：实现前制定的验收清单。
- `TESTING.md`：实测结果、修复循环与测试边界。
