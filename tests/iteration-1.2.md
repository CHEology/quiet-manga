# v1.2 极简顶栏验收

- 删除侧栏和底栏，页码及 < > 翻页按钮位于顶栏中央。
- 目录、上一章、下一章从设置中独立；首章上一章禁用，目标链接仍正确。
- 模式保持细蓝色边框，常态按钮去掉独立底块；全屏、设置、退出使用一致线条图标。
- 设置仅保留宽度和自动进入，面板外点击、Escape、焦点行为不变。
- 向下阅读隐藏整条顶栏，向上或顶部边缘恢复；右侧无残余唤出区域。
- 在实际 Chrome 中验证整页/连续、页码输入、快捷键、手势、全屏以及 320/360/600/1000/1440px 排列。
- 原有故障和阅读位置回归保持；安装后在用户实际漫画页面核验版本、章节链接和最终布局。

- 章末为普通文档内容，保留约 60% 视口高度留白和上下章入口。
- 切章采用同源 HTML 获取、独立路径/签名解析和局部内容替换；文档不卸载，沉浸/全屏不退出。
- 目录在当前页面的原生模态框显示，支持当前章高亮、搜索、关闭和选择；仅当前漫画链接进入列表。
- 切章失败可重试、慢响应不能覆盖后选章节、返回历史恢复进度；请求不执行返回 HTML 中的脚本。

- 页码区使用镜像 SVG 符号和 3ch / 1ch / 3ch 对称数字格；章末两个入口等宽、68px 高、18px 文字，间距至少 24px。

- 页码输入聚焦时无外框、无底块，仅 1px 内侧下划线；正常状态位置和尺寸不变。
