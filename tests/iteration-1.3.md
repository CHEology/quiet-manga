# iPad 验收清单（实现前）

- 连续模式两指分开/合拢改栏宽；以指间的漫画内容为锚点。整页模式缩放图片。
- 单指上下滚动由浏览器处理；轻点画布切换顶栏，不翻页。拖动、长按、捏合松手和取消不触发轻点。
- 章末链接、设置滑块、输入框及目录触摸不被画布吞掉。
- 横竖屏、窄分屏和 Safari 栏高度变化保持当前页与页内位置；不锁定方向。键盘输入、可触控面积和安全区可用。
- 旋转/退出/切章终止手势，不应用过时的帧；偏好可以持久保存。
- 在可用 WebKit 和 Chrome 上区分合成触摸、窗口尺寸与实体 iPad 证据，回归桌面交互。
- 提供能从 iPad 下载的单脚本安装包，不依赖 Mac 的 localhost。
