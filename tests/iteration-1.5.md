# 双页实现前验收项

- 顶栏继续用「整页／连续」，整页设置才显示「单页／双页」。初次使用为单页；双页的方向与首页配对选项按需出现。
- 两张竖图等高、贴缝、完整显示。横图与方图独占，封面可单独显示，章末奇数页可读。
- 左向右和右向左可切，图像不会镜像；键盘、箭头、页码范围及输入跳页一致。按作品记住偏好。
- 横屏且可用宽度至少 800px 才并排，窄屏或连续模式仍可单页阅读；切换、旋转、刷新和切章不丢目标页。
- 快速翻组、慢图、相邻页加载失败、重试及切换模式取消旧请求。双页捏合、双击和缩放还原完整画面。
- 在用户 Chrome 检查两套外观、设置打开/关闭、触控大小、轴线与书缝；回归已有整页与连续模式。发布同一个 userscript。
