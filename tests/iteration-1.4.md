# 验收清单（实现前）

1. 用 120 章、单章、无匹配三种情况复现目录，测列表底边到弹框底边的距离；长目录应填满可用高度，短目录、空结果按内容收缩。
2. 在桌面、iPad 竖屏／横屏、窄分屏和低高度下，验证标题、搜索保持可见，仅列表滚动，最后一章能滚到；打开目录不移动漫画。
3. 整页和连续顶栏均没有放大／还原按钮；桌面双击、Esc、触控板捏合以及触屏捏合、双击照常。
4. 浅色只改变阅读器与浮层，不改图片色彩、尺寸或读点；保留细蓝选中线。深色为默认，手动选择和跟随系统可以持久保存，切章／刷新不丢。
5. 验证发布 JS 和 ZIP 相同；在本机真实桌面浏览器验证布局，并标明触屏和实体设备的区别。
