# v1.1 验收计划

- 连续模式：横向双指滑动和捏合改变宽度；普通竖向滚动保持浏览器默认行为。
- 整页模式：捏合与横滑连续缩放，双击/Escape 恢复；指针附近内容保持位置。
- 手势连发、上下限、窄屏有效宽度、关闭/切换模式后无延迟操作；宽度持久保存。
- 调宽保持当前页及页内位置，加载和尺寸变化不产生跳动。
- 设置面板：点击内部不收起，画布/顶栏/底栏外部点击收起，按钮正常生效，设置按钮可连续开关，Escape 收起并恢复焦点。
- 顶栏等高对齐，模式选中为 1px 蓝框，按钮在 360px 宽屏不溢出，全屏入口直接可见。
- 本机 Chrome 回归：核心浏览器用例、响应式尺寸、真实点击/滚动/全屏，以及手势路径压力测试。
- 分开记录合成 wheel 事件测试与物理触控板手势实测，不把前者称为后者。

- 全屏画布四边贴合视口；翻页栏位于右侧；向下滚动隐藏顶部与侧栏，向上滚动/边缘悬停/键盘恢复；面板打开时不隐藏；退出全屏恢复普通布局及阅读位置。

结果：核心 8/8，浏览器 31/31，响应式 4/4。原生 Chrome 点击、横/竖向滚动、全屏进出通过。物理手指捏合未由自动化工具实测，已验证 Chrome ctrl+wheel 手势事件路径。
